# Roblox Sprint Script

This project contains a script to make the player sprint when holding the shift key. It is designed for Roblox games and provides a simple yet effective way to enhance player movement by allowing them to sprint when the shift key is pressed.

## Install

1. Place the `SprintController.server.lua` script in the `ServerScriptService` in Roblox Studio.

## Use

1. Run the game to test the sprint functionality.
